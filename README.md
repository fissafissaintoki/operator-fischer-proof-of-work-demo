# Prompterator

**Live:** https://www.prompterator.de

Prompterator ist ein KI Prompt Generator für strukturierte Arbeitsartefakte.

## Zweck

Prompterator verwandelt Rohinput in:

- Problemklasse
- Arbeitsmodus
- Artefakt-Blueprint
- Qualitätsprüfung
- Governance
- Masterprompt
- nächste Schritte

## Operator Fischer Method

```text
Rohinput -> Problemklasse -> Modus -> Artefakt -> Qualitätsprüfung -> Governance -> Wiederverwendung
```
