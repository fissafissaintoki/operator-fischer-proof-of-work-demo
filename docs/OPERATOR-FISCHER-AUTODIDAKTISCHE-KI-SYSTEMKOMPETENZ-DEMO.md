# OPERATOR FISCHER // AUTODIDAKTISCHE KI-SYSTEMKOMPETENZ

> Vom Rohproblem zum wiederverwendbaren KI-Arbeitsstandard.

---

## 1. Kompetenzname

**Autodidaktische KI-Systemkompetenz**  
International: **Self-Directed AI Systems Learning**

Diese Kompetenz beschreibt die Fähigkeit, KI-Systeme eigenständig zu erschließen, Muster zu erkennen, aus Versuchen robuste Workflows abzuleiten und daraus wiederverwendbare Arbeitsstandards zu bauen.

---

## 2. Operator-Definition

Operator Fischer arbeitet nicht nach starrer externer Vorlage, sondern entwickelt KI-Arbeitsfähigkeit durch operative Mustererkennung:

```text
Rohproblem
→ Versuch
→ Beobachtung
→ Mustererkennung
→ Struktur
→ Workflow
→ Test
→ Verbesserung
→ Artefakt
→ Wiederverwendung
```

Der Skill liegt nicht darin, einzelne Prompts zu schreiben. Der Skill liegt darin, aus chaotischem Rohinput ein kontrollierbares KI-Arbeitssystem zu formen.

## 4. Demonstration: aus Problem wird Operator-Workflow

### Rohinput

```text
Meine Webapp funktioniert optisch nicht sauber. Ein Banner wird nicht angezeigt.
Ich weiß nicht, ob es am HTML, CSS, Cache, Git, CSP oder Deployment liegt.
```

### Operator-Fischer-Verarbeitung

| Schritt | Operator-Denken | Ergebnis |
|---|---|---|
| Problemklasse | UI-/Deployment-/Repo-Diagnose | kein blindes Weiterbauen |
| Hypothesen | Cache, CSP, Bildpfad, Base64, Git-Stand | Ursachenbaum |
| Workflow | Claude/Codex bekommt Schrittfolge | kein Herumraten |
| Governance | keine Secrets, kein Force-Push, keine privaten Dateien | sichere Grenzen |
| Tests | Healthcheck, py_compile, Git-Diff, Browser-Reload | prüfbare Umsetzung |
| Rollback | Commit, Revert, Stash, Notfallpfad | rückbaubar |
| Artefakt | Workflow-Prompt + Repo-Dokumentation | wiederverwendbar |

### Ergebnis

Aus einem unklaren Problem entsteht ein kontrollierter Arbeitsablauf:

```text
Diagnose → Repo-Validierung → Dateiänderung → Test → Commit → Push → Browser-Prüfung → Rollbackoption
```
