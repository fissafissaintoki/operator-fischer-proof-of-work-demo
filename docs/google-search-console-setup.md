# Google Search Console Setup für prompterator.de

## Ziel

prompterator.de in Google Search Console verifizieren und Sitemap einreichen.

## Schritt 1: Property anlegen

1. Google Search Console öffnen.
2. Neue Property hinzufügen.
3. Property-Typ: Domain.
4. Domain eintragen:

```text
prompterator.de
```

## Schritt 2: DNS-Verifizierung

Google gibt einen TXT-Eintrag aus, ungefähr:

```text
google-site-verification=...
```

Diesen TXT-Eintrag bei checkdomain in der DNS-Verwaltung von prompterator.de hinterlegen.

## Schritt 3: Verifizieren

Zurück in Google Search Console auf Verifizieren klicken.

## Schritt 4: Sitemap einreichen

Nach erfolgreicher Verifizierung:

```text
https://www.prompterator.de/sitemap.xml
```

unter Sitemaps einreichen.

## Schritt 5: URL-Prüfung

Diese URLs einzeln prüfen und Indexierung anfordern:

- https://www.prompterator.de/
- https://www.prompterator.de/ki-prompt-generator
- https://www.prompterator.de/ki-use-case-generator
- https://www.prompterator.de/operator-fischer-method

## Hinweis

Indexierung ist nicht sofort Ranking. Danach braucht die Seite Inhalte, externe Links und wiederkehrende Nutzersignale.
