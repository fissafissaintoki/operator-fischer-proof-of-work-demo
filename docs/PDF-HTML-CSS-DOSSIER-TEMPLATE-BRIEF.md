# Prompterator HTML/CSS Dossier Template Brief

## Entscheidung

Der bisherige ReportLab-Pfad funktioniert technisch, erreicht aber nicht die gewuenschte visuelle Dossier-Qualitaet. Der naechste Pfad ist ein HTML/CSS-basiertes Dossier-Template als visuelle Zielarchitektur.

## Zielbild

Prompterator soll ein PDF/Print-Dossier erzeugen, das wie ein hochwertiges Infografik-Poster, Executive Briefing und Use-Case-Booklet wirkt.

## Referenzstil

- Dunkle technische Infografik
- Modulare Panels
- Hero-Cover
- Prozessvisualisierung
- KPI-/Status-Karten
- Executive-Dashboard
- Weniger Fliesstext
- Mehr Dossier-/Poster-Charakter

## HTML/CSS-Seitentypen

1. Hero Cover
2. Executive Dashboard
3. Use-Case Canvas
4. Prozessmodell
5. Rollenmatrix
6. Risiko- und Annahmenmatrix
7. Fallbeispielseite
8. Governance Board
9. Schulungsseite
10. Management-Empfehlung

## No-Go

- Textdump
- Bulletpoint-Friedhof
- Tabellenwueste
- zufaellige Bilder
- leerer Verwaltungsbericht
- Standard-PDF-Optik

## Technische Zielarchitektur

Phase 1: statisches HTML/CSS-Dossier-Template
Phase 2: Server-Endpunkt /dossier-preview als HTML-Vorschau
Phase 3: Print-CSS stabilisieren
Phase 4: PDF-Konvertierung pruefen

## Akzeptanzkriterium

Die ersten drei Seiten muessen optisch wie ein Executive Infographic Dossier wirken, bevor PDF-Konvertierung weiter optimiert wird.
