# Memory Seed – HZ Skill Extraction

## Status
Kanonisch fuer Operator Fischer.

## Trigger
Wenn Operator Fischer schreibt:

- `hz`
- `füge hinzu`
- `hinzufügen`
- `das ins Memory`
- `speichere diesen Skill`

soll aus dem aktuellen Kontext kein kompletter Chatdump entstehen, sondern ein kuratierter, wiederverwendbarer Skill- oder Musterextrakt.

## Bedeutung
`hz` bedeutet:

Extrahiere aus dem aktuellen Kontext eine wiederverwendbare Fähigkeit, Arbeitslogik, Promptstruktur oder Kompetenz und speichere sie sauber als KnowledgeOS-Artefakt.

## Arbeitslogik

Rohinput -> Skill erkennen -> Kompetenz benennen -> Struktur extrahieren -> Wiederverwendung definieren -> Governance prüfen -> Artefakt speichern -> bei Bedarf als Memory-Kern markieren

## Standard-Extrakt
Ein HZ-/Memory-Skill-Extrakt enthält:

1. Skillname
2. deutsche Bezeichnung
3. internationale Bezeichnung
4. Definition
5. Trigger / Wann nutzen?
6. Arbeitslogik
7. Teilfähigkeiten
8. Qualitätskriterien
9. Risiken / Grenzen
10. wiederverwendbares Template
11. Portfolio-/Bewerbungsformulierung
12. Status: aktiv / experimentell / deprecated

## Governance

- Kein kompletter Chat wird gespeichert.
- Keine privaten Daten unnötig speichern.
- Keine Secrets, API-Keys, Tokens oder Passwörter speichern.
- Keine Rohlogs ohne Verdichtung speichern.
- Mensch bleibt Owner, KI extrahiert und strukturiert nur.
- Primärer Speicherort ist KnowledgeOS / GitHub-Artefakt.
- Nur stabile, wiederverwendbare Kompetenzen werden als Memory-Kern markiert.

## Kurzregel

`hz` = Fähigkeit extrahieren, benennen, strukturieren, wiederverwendbar machen und als KnowledgeOS-/Memory-Artefakt sichern.
