## AI-Operations-Fähigkeiten

### 1. Anforderungen strukturieren

Unklare Anforderungen werden nicht direkt umgesetzt, sondern zuerst klassifiziert:

```text
Rohinput -> Problemklasse -> Zielbild -> Artefakt -> Prüfung -> Wiederverwendung
```

### 2. Coding-Agenten kontrollieren

Claude Code, Codex und vergleichbare Systeme werden nicht nur befragt, sondern über ausführbare Workflow-Prompts gesteuert:

```text
Rolle -> Workspace -> Scope -> Dateien -> Tests -> Diff -> Commit -> Push -> Rollback
```

### 3. Fehlerquellen operativ absichern

Vor Dateiänderungen werden Workspace, Repository, Remote und Pflichtdateien geprüft. Bei falscher Umgebung wird gestoppt.

### 4. Governance einbauen

Keine Secrets, keine privaten Dokumente, kein Force-Push, keine Arbeit am falschen Projekt, keine ungeprüften Änderungen.

### 5. Ergebnisse wiederverwendbar machen

Neue Fähigkeiten werden über `hz` als strukturierte Skill-Artefakte extrahiert und in KnowledgeOS dokumentiert.
